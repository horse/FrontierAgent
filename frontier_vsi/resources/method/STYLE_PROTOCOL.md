# Style Protocol

Editorial process is fixed; book voice is variable. Each book defines a Style Profile, Voice Specification, sample prose and approved Voice Anchors. Samples are evidence about syntax, paragraphing, register, narrative distance, explanation, example density, quotation habits and rhythm; they are not phrase banks. Style calibration tests opening, core explanation and high-risk prose before the control chapter. A material style change invalidates downstream style/authorial approvals.
