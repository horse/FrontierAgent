# VSI Core

FrontierVSI produces short public-knowledge nonfiction for intelligent non-specialist readers. It is not a compressed encyclopedia. The book must find the shortest non-distorting cognitive path through the subject: one central promise, one explanatory spine, selective high-leverage cases, an honest dispute map, and a useful exit into further reading.

Fixed rules: one primary axis; each chapter has one irreplaceable cognitive job; explain before naming; examples carry explanatory pressure; evidence supports prose without leaking workflow residue; uncertainty and disagreement remain visible; structural failures return upstream instead of being hidden by sentence polish.
